# 待辦：Google 登入 + Drive 儲存詢問紀錄

> 整理自 2026-10-29 的討論，尚未實作。日後重新審視時，先看「待決定的問題」與「前置準備」。

## 目標
使用者可用 Google 帳戶登入，把詢問紀錄存在**自己的 Google Drive**，換裝置也能還原。
遇到機關 Google Workspace 帳號被管理員擋下時，顯示訊息，改為僅存本機，並提供手動備份。

## 已定案
- 採用 **Google Identity Services + Drive `appDataFolder`**（權限範圍 `drive.appdata`）。
  - 資料只在使用者瀏覽器與其自己的 Google 帳號間流動，不經過我們控制的伺服器。
  - 該資料夾在使用者 Drive 介面中看不到，其他應用程式與開發者都讀不到。
  - `drive.appdata` 屬非敏感權限，通常不需送 Google 審核。
- 遇到機關帳號擋下時：顯示對應訊息，說明只能存本機或手動備份。
- 純前端、無自建後端；OAuth 用戶端 ID 是公開資訊，可放前端。

## 現況與限制（來自程式碼）
- 紀錄為 `QuestionRecord[]`（最新在前），整包存 localStorage 的 `docmind.history`（`src/services/storage.ts`）。
- 每筆有穩定的 `id` 與 `timestamp`，可用 `id` 去重合併。
- `usedChunks`（引用原文段落）是體積主要來源。
- `saveHistory` 超量時會**靜默丟掉較舊的一半**，雲端同步不可沿用此行為。
- 目前沒有匯出／匯入功能。

## 設計重點

### 帳號偵測與降級
- ID Token 的 `hd` 欄位有值代表 Workspace 帳號，但**不能據此判斷能否存 Drive**（管理員政策查不到）。
- 實際作法：嘗試授權，被擋（`access_denied`、`admin_policy_enforced` 等）或之後 Drive API 持續回 403，就降級為本機模式。
- 對 `hd` 有值的帳號，登入前先預告可能被組織擋下。
- 降級訊息（草稿）：「您的組織帳號可能不允許第三方應用程式存取雲端硬碟，詢問紀錄只能儲存在本機。您可以使用『匯出備份』手動保存。」

### 資料格式（Drive 上的 `history.json`）
```
{
  "version": 1,
  "updatedAt": <毫秒時間戳>,
  "records": [ ...QuestionRecord ],
  "deletedIds": { "<id>": <刪除時間> }
}
```
- `version`：日後遷移格式用。
- `deletedIds`（墓碑）：避免在 A 裝置刪除的紀錄被 B 裝置的舊資料復活，保留約 90 天後清掉。
- 合併：`records` 以 `id` 聯集，同 `id` 取較新者，再套用 `deletedIds`（刪除優先）。

### 同步策略
- 登入時合併一次（Drive ↔ 本機），結果寫回兩邊。
- 新增／刪除紀錄：本機立即更新，Drive 寫入節流（約停止操作 3 秒後），頁面隱藏／關閉時嘗試最後一次寫入。
- 寫入前用 Drive 的 `modifiedTime` / `version` 檢查雲端是否更新，若有則先合併再寫。
- 不做輪詢；提供「立即同步」按鈕。

### Token 過期
- Access token 約 1 小時，純前端沒有 refresh token。
- 遇 401 先無聲重取（`requestAccessToken({ prompt: '' })`）；失敗則顯示「同步已暫停，點此重新連線」，紀錄仍保留本機。
- 介面顯示同步狀態（已同步／同步中／已暫停／失敗）與最後同步時間。

### 體積控制
- 同步版本可精簡：不存或只存部分 `usedChunks`。
- 本機配額不可再靜默砍半；超量時要提示使用者。

### 手動備份（降級方案，也是通用後備）
- 匯出：下載含日期檔名的 `.json`。
- 匯入：與現有紀錄**合併**（以 `id` 去重），顯示「新增 N 筆、略過 M 筆」；需驗證格式與 `version`，不信任檔案內容。
- 不依賴 Google，可獨立先做。

### 登出與隱私
- 登出時撤銷 token（`google.accounts.oauth2.revoke`），詢問是否清除本機紀錄，預設保留。
- 共用電腦風險：首次登入時要提示「本機現有 N 筆紀錄將同步到此帳號」。
- README 隱私說明需補一段：選用功能、僅存使用者自己的 Drive、只用 `drive.appdata`、開發者看不到。

## 風險備忘
- 機關 Workspace 管理員可能禁止第三方存取 Drive，登入會被擋。
- 兩台裝置同時使用的寫入衝突，必須靠合併而非整份覆蓋。
- 問答內容可能含機關內部資訊，上雲前須確認規範。
- 瀏覽器可能擋下 token 更新彈窗，需要手動重新連線流程。
